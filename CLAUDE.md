## Allineamento (obbligatorio)
Questo progetto vive su più computer ed è un repo git indipendente (vedi `~/progetti/repos.txt`).
- **Prima di iniziare**: `git pull --ff-only` (oppure `~/progetti/allinea.sh pull` per allineare tutto).
- **A fine lavoro**: commit + `git push`, poi aggiorna `~/progetti/gestione-siti/diario.md`.
- Non lasciare modifiche solo in locale. Non committare segreti (`.env`, password, chiavi API).
